##데이터##
- 반려동물 등록 현황(자치구 별 25개 파일 수집)
- 서울시 주요 공원현황
- 한국문화정보원_전국 반려동물 동반 가능 문화시설 위치 데이터
- 서울특별시_인구밀도(구별) 통계

##클린징 과정 설명##
1. 25개의 자치구 별 반려동물 등록 현황 개별 파일-> 하나로 통합
- 컬럼명 통일(자치구, 등록동물수 등)
- 특정 자치구에만 존재하는 변수 제거(대행업체, 집계기준 등)
2. 서울시 주요 공원현황
-  GRS80TM 컬럼 제거
-  X좌표(WGS84) → 경도, Y좌표(WGS84) → 위도 로 컬럼명 변경
3. 전국 반려동물 동반 가능 문화시설 위치 데이터
- 서울시 데이터만 추출
- 카테고리1 제거: 단일값(반려동물업)만 존재
- Y/N 컬럼 → 1/0로 변환
4. 서울특별시_인구밀도(구별) 통계
- 컬럼명 변경

공통적인 클린징: 필요한 변수 외 다른 변수 컬럼들 삭제
- 추가적으로 AI의 도움을 받아 전처리 후 데이터베이스 생성 진행
- 각 테이블의 자치구 데이터 컬럼명을 'district'로 통일
- 공원데이터에서 좌표 결측치 행 제거
- 모든 테이블에 id PK추가

##시각화 결과##
1. 면적 대비 동물 의료시설 접근 용이성
- 자치구 면적 데이터와 병원과 약국 등 반려동물 의료시설 데이터를 활용하여 접근 용이성을 시각화 함
- AI가 동물등록 수 대비 시설 수 분석을 추가해서 최종적으로 3개의 변수를 활용한 버블 차트를 생성함
- 중구·동대문구·양천구이 면적당 의료시설 밀도가 높음
- 서초구·종로구는 면적이 넓어 밀도가 낮지만, 등록 동물 수 대비 시설은 많음
2. 실내/실외 반려시설 유형과 지역특성
- 동물동반시설 데이터에 있던 실내/실외 시설 개수를 비율로 나타내어 가로막대그래프로 표현하여, 자치구간 비교와 자치구내 비교가 가능함
- 실내와 실외가 둘 다 포함된 시설들이 있어 실내/실외 비율의 합이 100이 넘어가는 경우도 있음
- 전반적으로 실내시설의 비율이 높아, 실외 비율이 높은 순으로 차트 시각화함(차별화되는 지역 추출)
3. 반려동물 밀집 지역 분석
- 면적과 인구 대비 반려동물 등록 수를 분석하여 반려동물 친화적인 자치구를 분석해보고자 함
- 크기와 색을 활용하여 반려동물의 수와 반려화율을 한눈에 비교할 수 있도록 차트를 생성함
- 추가적으로 인구밀도와 반려화율 차트를 통해 인구밀도와 반려화율의 음의 상관관계가 있다는 것을 직관적으로 파악할 수 있음
