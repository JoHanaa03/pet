##클린징 과정 설명##
1. 25개의 자치구 별 반려동물 등록 현황 개별 파일
- 파일 통합: 자치구마다 공공데이터포털에 개별 파일로 업로드되어 있어, 25개 파일을 하나의 파일로 통합하는 과정 필요
- 컬럼명 통일: 동일한 정보를 담고있는데 컬럼명이 다른 변수 존재. 동물 등록 수를 나타내는 컬럼이 등록동물수(마리), 반려동물수, 동물등록 수, 합계 등 여러 표현으로 작성되어 있어, 동물등록수, 동물소유자수 등 공통 컬럼명으로 통일
- 자치구별 고유 변수 제거: 일부 자치구에만 존재하는 컬럼은 통합 테이블에서 의미 있는 분석이 어려울 것이라 판단하여 제거함. 강동구·강북구 등의 시군구(직접등록), 대행업체, 기타(이벤트등) 컬럼등은 모든 자치구에 존재하지 않아 삭제 후 합산 값만 유지. 동물소유자당동물등록수, 집계기준, 데이터기준일자 등 분석과 직접적인 연관이 없는 컬럼도 함께 제거
- 중구: 등록 수 컬럼 자체가 없어서, 동물소유자수 × 소유자당 등록수로 계산하여 추정값 산출
2. 서울시 주요 공원현황
-  GRS80TM 컬럼 제거
-  X좌표(WGS84) → 경도, Y좌표(WGS84) → 위도 로 컬럼명 변경
3. 전국 반려동물 동반 가능 문화시설 위치 데이터
- 전국의 데이터를 포함하고 있는 원본 파일에서 분석에 필요한 서울시 데이터만 추출
- 카테고리1 제거: 카테고리1 컬럼은 전체 행에 걸쳐 반려동물업이라는 단일값만 존재하여 분석에 불필요하다고 판단
- Y/N 컬럼 → 1/0 변환: 주차 가능여부, 반려동물 동반 가능정보, 장소(실내) 여부, 장소(실외) 여부 4개 컬럼이 문자열 'Y'/'N'으로 저장되어 있었으며. 통계 분석 및 SQL 연산이 원활하도록 1/0으로 변환함.
4. 서울특별시_인구밀도(구별) 통계
- 컬럼명 변경: 원본 컬럼명을 분석 목적에 맞게 간결하게 변경

공통적인 클린징: 필요한 변수 외 다른 변수 컬럼들 삭제
- 추가적으로 AI의 도움을 받아 전처리 후 데이터베이스 생성 진행
- 테이블 간 JOIN을 용이하게 하기 위해서 각 테이블의 자치구 데이터 컬럼명을 'district'로 통일
- 공원데이터에서 좌표 결측치 행 제거
- 모든 테이블에 id 컬럼을 추가하여 기본키로 설정하고, 자동 증 방식으로 부여헸음을 확인

##시각화 결과##
1. 면적 대비 동물 의료시설 접근 용이성
- 자치구 면적 데이터와 병원과 약국 등 반려동물 의료시설 데이터를 활용하여 접근 용이성을 시각화 함
- 단순히 시설의 개수만 비교하는 것이 아니라, 면적 대비 의료시설 수를 활용하여 실제 생활에서 체감할 수 있는 접근성을 분석하고자 함
- AI가 동물등록 수 대비 시설 수 분석을 추가해서 최종적으로 3개의 변수를 활용한 버블 차트를 생성함
- 분석 결과 중구·동대문구·양천구는 면적당 의료시설 밀도가 높게 나타났음. 이는 상대적으로 거주자들의 생활 반경 안에서 동물병원과 약국에 접근할 가능성이 높다는 것을 의미하고, 반려동물 응급 상황이나 정기 진료등의 상황에서 필요시 즉각적으로 접근이 가능하며 의료 접근성이 우수한 지역으로 해석할 수 있음.
- 서초구와 중구를 비교해보면, 시설의 절대 수와 실제 체감 접근성에서는 거리 편차가 발생할 수 있다는 사실을 알 수 있음. 즉, 공급 규모 자체보다 분산 구조가 접근성에 영향을 미칠 수 있음을 의미함.
- 차트의 우상단에 위치한 자치구는 ‘공간 접근성’과 ‘수요 대비 공급’ 모두 우수한 이상적인 반려동물 의료 환경을 갖춘 지역으로 볼 수 있으며, 반대로 좌하단에 위치한 지역은 의료 인프라 개선 우선 지역으로 해석할 수 있음.
- 이 차트는 서울시 반려동물 의료 인프라의 핵심 문제가 단순 공급 부족이 아니라, “수요와 공간 구조에 맞는 균형 있는 분배”에 있음을 보여주는 분석이라고 할 수 있음.

2. 실내/실외 반려시설 유형과 지역특성
- 동물동반시설 데이터에 있던 실내/실외 시설 개수를 비율로 나타내어 가로막대그래프로 표현하여, 자치구간 비교와 자치구내 비교가 가능함
- 실내와 실외가 둘 다 포함된 시설들이 있어 실내/실외 비율의 합이 100이 넘어가는 경우도 있음
- 전반적으로 실내시설의 비율이 높아, 실외 비율이 높은 순으로 차트 시각화함(차별화되는 지역 추출)
- 분석 결과 대부분의 자치구는 실내 시설 비율이 높게 나타났는데, 이는 서울의 고밀도 도시 구조와 밀접한 관련이 있다고 볼 수 있음.
- 동대문구·중랑구와 같은 인구밀도 높은 도심 지역은 실외 활동 공간 확보가 어려워서, 반려동물 카페·실내 놀이시설·동반 쇼핑시설과 같은 실내 중심의 반려동물 문화가 발달한 것으로 볼 수 있음.
- 실외 비율이 높다고 공원 수가 많은 것은 아니라는 것을 확인할 수 있음
- 반려동물 친화 환경을 분석할 때는 반려시설 수와 실내/실외 비율, 공원의 수를 종합적으로 고려해야 총체적인 반려동물 시설의 경향성을 파악할 수 있다는 것을 확인함.

3. 반려동물 밀집 지역 분석
- 면적과 인구 대비 반려동물 등록 수를 분석하여 반려동물 친화적인 환경의 자치구를 분석해보고자 함
- 트리맵 시각화를 통해 크기와 색상을 동시에 활용함으로써, 등록동물 수와 반려화율을 직관적으로 비교할 수 있도록 차트를 생성함
- 트리맵을 통해서는 “규모는 크지만 반려화율은 낮은 지역”과 “규모는 작아도 반려친화도가 높은 지역”을 직관적으로 구분할 수 있으며, 이를 활용하여 반려동물 정책이나 인프라 개선 우선순위를 설정하는 데에 있어 유용한 기준이 될 수 있을거라 기대됨
- 대표적으로 강북구는 등록동물 수와 반려화율이 모두 높은 지역으로 나타났으며, 이는 단순한 인구 규모의 영향력만으로는 설명될 수 없으며, 실제 생활권 자체가 반려동물 양육에 친화적인 환경일 가능성을 의미함.
- 또한 서울 내 대표적인 반려친화 생활권이 반드시 고소득 지역 중심으로만 형성되는 것은 아니라는 점도 파악할 수 있었음.
- 두번째 그래프를 통해서는 인구밀도와 반려화율의 음의 상관관계를 직관적으로 파악할 수 있며, 인구가 밀집된 도심 지역일수록 주거 공간 제약, 산책 공간 부족, 생활소음 문제 등으로 인해 반려동물을 키우는 비율이 상대적으로 낮아질 가능성을 의미한다고 볼 수 있음.

4. 전체적인 인사이트
- 서울시의 반려동물 친화 환경은 단순히 시설 수가 많은 지역에서 형성되는 것이 아니라, 도시 구조·인구밀도·주거환경·공간 접근성 등이 복합적으로 작용한다는 점을 확인할 수 있었음

##개선점 및 추가 활용 방안##
이번 분석에 활용한 데이터 외에 다른 데이터들을 활용한다면 더욱 풍부한 인사이트를 얻을 수 있을 것으로 예상함
- 자치구별 1인 가구 비율, 연령대 데이터: 반려동물 양육과 가구 형태·사회구조 간의 관계를 더욱 구체적으로 분석할 수 있을 것임
- 특히 청년층과 1인 가구 비율이 높은 지역에서 반려화율이 높게 나타나는지 분석한다면, 최근의 도시형 반려문화 변화와 연결된 분석이 가능할 것으로 생각됨
- 소득 수준이나 주택 유형 데이터: 고소득 지역에서 반려 서비스가 집중되는 현상이나 아파트·다세대 주택 비율에 따른 반려동물화 차이 등을 알아볼 수 있을 것으로 생각됨
- 실제 공원 면적, 산책로 데이터, 유기동물 발생 데이터: 단순 시설 현황을 넘어, 실제 반려동물 생활 만족도나 지역 내 반려동물 문제까지 함께 분석할 수 있을 것으로 생각됨.
